feat(multiworld): implement structure-based map export/load system and cleanup docs

Summary:
Introduced a new system in MultiWorld for exporting, loading, and deleting large multi-structure maps. This enables transferring massive terrain sections into custom void worlds using segmented structure files. Also removed the outdated server-forms.md documentation.

Key Features & Changes:
- 🗺️ Map Export & Load System: 
  • Added `/pmmpcore:export` command to slice and export large map areas into multiple manageable structure files (`mapName_X_Z`).
  • Added `/pmmpcore:load` command to stitch and load these segmented map structures seamlessly into custom void worlds.

- 🗑️ Map Cleanup Tool: 
  • Added `/pmmpcore:delete_map` command to recursively iterate and safely delete all structure segments associated with a previously exported map, keeping the world database clean.

- 🔑 New Commands & Permissions: 
  • Registered `pperms.command.mw.export` and `pperms.command.mw.load` into the default PurePerms initialization seed (`main.js`).
  • Added standalone command registrations in `commands.js` to handle the new map management workflows.

- 📚 Documentation Cleanup: 
  • Deleted `server-forms.md` as its contents are deprecated or have been migrated.
